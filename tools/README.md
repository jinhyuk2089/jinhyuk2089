# 네이버 뉴스 자동 수집·검증·종합 글쓰기

`naver_news_writer.py`는 키워드를 넣으면 네이버 뉴스에서 자료를 모으고, 링크를 하나씩 열어 검증한 뒤, 검증된 자료가 10건 이상이면 Claude가 출처 번호를 단 기획기사와 블로그 글을 씁니다.

## 하는 일

| 단계 | 내용 |
|---|---|
| 1. 수집 | 키워드마다 네이버 검색 API로 **정확도순(검색 상위)** 과 **최신순** 기사를 가져오고, 같은 링크는 하나로 합칩니다. 직접 고른 링크(`--links`)도 함께 넣습니다. |
| 2. 검증 | 기사 링크를 실제로 열어 응답이 정상인지, 원문 제목이 검색 결과와 일치하는지, 발행일과 언론사명을 확인합니다. 열리지 않거나 제목이 다른 자료는 제외합니다. |
| 3. 이슈 묶기 | 제목이 비슷한 기사를 하나의 이슈로 묶고, 몇 개 언론사가 다뤘는지 셉니다. 정확도순 순위, 최신성, 이슈 규모, 공공기관 자료 여부로 점수를 매깁니다. |
| 4. 표시 | 정확도순 10위 안은 **상위노출**, 언론사 3곳 이상이 다룬 이슈는 **이슈**, 점수 상위 5건은 **픽**으로 표시합니다. |
| 5. 글쓰기 | 검증 자료가 기준(기본 10건) 이상이면 Claude가 자료와 현장 메모만 근거로 글을 씁니다. 사실마다 [번호]로 출처를 달고, 자료에 없는 수치는 [확인 필요]로 남깁니다. |

결과 폴더에는 다음 파일이 생깁니다.
- `sources.json`: 검증된 자료 목록. 참여 도구의 **뉴스 종합** 탭에서 불러옵니다.
- `report.md`: 자료 검증 정리표와 이슈 묶음, 제외한 자료와 그 이유
- `article.md`: 기획기사와 블로그 글

## 준비

1. **네이버 검색 API 키**: [네이버 개발자센터](https://developers.naver.com/)에서 애플리케이션을 등록하고 사용 API로 "검색"을 고르면 Client ID와 Client Secret이 나옵니다.
2. **Anthropic API 키**: 글쓰기 단계에만 필요합니다. `--no-write`로 수집·검증만 할 때는 없어도 됩니다.
3. Python 3.10 이상

```bash
pip install -r tools/requirements.txt
export NAVER_CLIENT_ID=발급받은_ID
export NAVER_CLIENT_SECRET=발급받은_SECRET
export ANTHROPIC_API_KEY=발급받은_키
```

## 실행 예시

```bash
python tools/naver_news_writer.py \
  -k "노인복지:노인맞춤돌봄서비스" -k "지역복지:동두천 복지" -k "장애인:장애인 활동지원" \
  --links links.txt \
  --note "10월 들어 복지관 돌봄 상담이 주 5건에서 12건으로 늘었다" \
  --mode both --length 3000
```

`links.txt`에는 네이버 뉴스 홈의 언론사 픽, 랭킹, 섹션 기사나 공공기관 보도자료처럼 직접 고른 링크를 한 줄에 하나씩 적습니다.

```
https://n.news.naver.com/article/000/0000000000 | 노인복지 | 언론사 픽 기사
https://www.mohw.go.kr/board.es?... | 복지정책 | 보건복지부 보도자료
```

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| `-k` | (필수) | `분야:키워드` 또는 `키워드`. 여러 번 쓸 수 있습니다. |
| `--per-sort` | 30 | 키워드·정렬마다 가져올 기사 수 (최대 100) |
| `--days` | 30 | 최근 며칠 안의 기사만 |
| `--links` | 없음 | 추가 링크 파일 |
| `--note`, `--note-file` | 없음 | 현장 경험이나 별도 텍스트. 경험은 여기에 적은 내용만 글에 들어갑니다. |
| `--min-verified` | 10 | 글을 쓰기 위한 최소 검증 자료 수 |
| `--mode` | both | `article` 기사, `blog` 블로그 글, `both` 둘 다 |
| `--no-write` | 꺼짐 | 수집·검증만 합니다. |

## GitHub에서 실행하기

저장소 Settings → Secrets and variables → Actions에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `ANTHROPIC_API_KEY`를 등록합니다. 그다음 Actions 탭의 **네이버 뉴스 종합 글쓰기**에서 Run workflow를 누르고 키워드(세미콜론으로 구분)를 넣으면 됩니다. 결과는 실행 화면의 Artifacts에서 `news-output`으로 내려받습니다.

## 지켜야 할 것

- 네이버 뉴스 페이지를 긁어 오지 않고 공식 검색 API만 씁니다. 기사 본문은 저장하거나 글에 옮기지 않고 제목, 요약, 메타 정보만 씁니다.
- 검색 상위에 있다고 해서 그 기사가 사실이라는 뜻은 아닙니다. `article.md`는 초안이므로, 발행 전에 사람이 [번호]마다 원문과 대조하고 [확인 필요]를 채워야 합니다.
- 네이버 검색 API에는 하루 호출 한도가 있습니다. 한도는 개발자센터에서 확인하세요.
