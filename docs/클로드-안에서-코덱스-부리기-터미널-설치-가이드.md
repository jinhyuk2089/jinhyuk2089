# 클로드 안에서 코덱스 부리기 — 터미널 설치 가이드

> 오픈AI 공식 플러그인 `codex-plugin-cc`로 클로드 코드 창을 떠나지 않고 코덱스에게 리뷰와 작업을 맡기는 법
>
> 사실 확인 기준일: 2026년 10월 16일 · 확인 대상: 공식 저장소 README와 플러그인 소스(v1.0.6)

---

## ❓ 왜 찾아봤나

클로드로 작업하다가 코덱스한테 물어보려면 터미널을 하나 더 띄우고, 하던 얘기를 복사해서 붙여넣어야 합니다. 대단한 일은 아닌데 **창을 옮기는 게 매번 귀찮았습니다.**

그렇다고 코덱스를 놓기도 아까웠습니다. 긴 작업을 붙잡고 갈 때 중간 디테일을 안 놓치는 건 확실히 코덱스 쪽이거든요.

그러다 오픈AI가 클로드 코드 안에서 코덱스를 부르는 플러그인을 공식으로 냈다는 걸 봤습니다. 창을 안 옮겨도 된다는 뜻이라 바로 깔아서 돌려봤고, 이 문서는 그 과정을 그대로 옮겨둔 거예요.

---

## 🧩 이게 뭔가

`openai/codex-plugin-cc`. 오픈AI 공식 계정이 **2026년 3월 30일**에 첫 커밋을 올린 저장소이고, 별은 **3만 4천여 개**(2026년 10월 16일 기준 34.3k)입니다. 라이선스는 Apache-2.0이에요. 경쟁사 제품 안에서 자기 에이전트가 돌게 만든 거라, 나온 것 자체가 이례적입니다.

중요한 건 **별도 프로그램이 아니라는 점**입니다. 이 플러그인은 내 컴퓨터에 깔려 있는 코덱스 CLI를 빌려 씁니다. 그래서 로그인도, 설정도, 요금도 원래 쓰던 코덱스 그대로예요.

✅ **할 수 있는 것 두 가지**

- **코드 리뷰를 맡긴다** — 클로드가 짠 걸 코덱스가 봅니다. 리뷰 명령은 읽기 전용이라 코드를 고치지 않습니다
- **작업을 통째로 넘긴다** — 막힌 버그 조사나 수정을 코덱스한테 시킵니다. 이쪽은 기본이 쓰기 권한입니다

✅ **준비물**

- ChatGPT 계정(무료 플랜 포함) 또는 OpenAI API 키
- Node.js 18.18 이상

## 📖 설치 — 터미널에서 네 줄

클로드 코드를 터미널에서 쓰고 계신다는 전제입니다. 아래를 순서대로 치면 됩니다.

- [ ] **1단계.** 마켓플레이스 등록 — 카탈로그만 추가하는 단계라 아직 아무것도 안 깔립니다

```
/plugin marketplace add openai/codex-plugin-cc
```

- [ ] **2단계.** 플러그인 설치

```
/plugin install codex@openai-codex
```

- [ ] **3단계.** 플러그인 불러오기 — 지금 창에서 `/reload-plugins`를 치거나 새 세션을 엽니다

```
/reload-plugins
```

- [ ] **4단계.** 준비됐는지 확인

```
/codex:setup
```

`ready: true`가 나오면 끝입니다. 제 경우는 이렇게 나왔습니다.

```
ready : true
codex : codex-cli 0.155.1
auth  : ChatGPT login active
```

![/codex:setup 실행 결과](02_setup결과.png)

#### /codex:setup 은 꼭 쳐야 하나

코드를 열어보니 **다른 명령들이 setup을 먼저 돌렸는지 검사하지 않습니다.** 코덱스가 이미 깔려 있고 로그인돼 있으면 건너뛰고 바로 `/codex:review`를 쳐도 됩니다.

다만 **코덱스를 한 번도 안 써본 분은 쳐야 합니다.** 코덱스가 없고 npm이 있을 때 「지금 설치할까요」를 물어보는 게 이 명령뿐입니다. 설치는 됐는데 로그인이 안 돼 있다면 `!codex login`으로 로그인하라고 안내해 줍니다.

## ⚠️ 저는 여기서 한 번 막혔습니다

설치는 됐는데 안 돌아갔습니다. 코덱스 CLI 자체가 깨져 있었습니다.

```
Error: spawn .../codex ENOENT
```

들여다보니 실행 파일이 있어야 할 자리에 **빈 폴더**만 남아 있었습니다. 버전이 올라가면서 폴더 구조가 바뀌는 지점에 걸린 것 같은데, 정확한 원인까지는 확인하지 못했습니다. 고치는 건 한 줄이었습니다.

```
npm install -g @openai/codex@latest
```

21초 걸렸고 **로그인은 그대로 살아 있었습니다.** 설정 파일도 건드려지지 않았고요. 혹시 `codex --version`부터 에러가 나면 이것부터 해보세요.

## 🫡 명령어는 일곱 개 (+ 점검용 setup)

이름만 보면 헷갈리는 게 몇 개 있어서, 언제 쓰는 건지 위주로 적어둘게요.

| 명령어 | 언제 쓰나 |
| --- | --- |
| `/codex:review` | 지금 작업한 걸 코덱스한테 검사받고 싶을 때. 읽기 전용이고, `--base <브랜치>`로 브랜치 비교도 됩니다 |
| `/codex:adversarial-review` | **설계 자체를 의심받고 싶을 때.** "이 방식이 맞냐"고 물고 늘어집니다. 이것도 읽기 전용 |
| `/codex:rescue` | 클로드가 막혔을 때 작업을 통째로 넘깁니다. 기본이 쓰기 권한 |
| `/codex:transfer` | 지금 대화를 코덱스 스레드로 옮기고, 이어갈 `codex resume <세션ID>` 명령을 찍어줍니다 |
| `/codex:status` | 백그라운드로 돌린 게 어디까지 갔는지 |
| `/codex:result` | 끝난 작업 결과 다시 보기 |
| `/codex:cancel` | 돌아가는 거 취소 |

✅ **review와 adversarial-review의 차이**

`review`는 "이 코드에 문제가 있나"를 봅니다. `adversarial-review`는 "이 설계가 어디서 무너지나"를 봐요. 그래서 **초점을 지정할 수 있는 건 뒤쪽뿐입니다** — 인증 쪽을 집중해서 봐달라거나, 캐싱 설계가 맞는지 따져달라거나 하는 식으로요. `review`에는 추가 지시를 붙일 수 없습니다.

```
/codex:adversarial-review 캐싱 무효화 설계가 동시성에서 버티는지 따져봐줘
```

✅ **rescue에 "읽기만 해"라고 하면**

`rescue`는 기본으로 쓰기 권한을 켜고 돌지만, 조사·진단만 해달라거나 읽기 전용으로 해달라고 말하면 쓰기를 켜지 않도록 되어 있습니다.

✅ **촬영·시연할 때 팁**

리뷰 명령에는 `--wait`를 붙이세요. 안 붙이면 변경 규모를 보고 「기다릴까요 / 백그라운드로 돌릴까요」를 한 번 물어봅니다. 붙이면 그 질문을 건너뛰고 바로 돌아가요. 반대로 길게 걸릴 작업이면 `--background`를 붙이면 됩니다.

```
/codex:review --wait
```

## 🚀 돌려보니 이랬습니다

말로만 하면 안 와닿을 것 같아 실제 숫자를 적어둡니다. 작은 테스트 저장소를 만들고 일부러 버그를 심은 다음 리뷰를 시켰습니다. 아래 시간은 제 환경에서 한 번 잰 값이라 참고만 하세요.

✅ **코드 리뷰 — 38.7초**

```
[P1] 반복 조건을 배열 길이 미만으로 되돌리세요 — cart.js:4-4
     i <= items.length는 배열 범위 밖의 items[items.length]까지 접근합니다.
     그래서 price를 읽을 때 TypeError가 납니다.
```

![/codex:review 결과 — P1 지적](01_리뷰결과_P1.png)

심각도와 파일·줄번호까지 붙어서 오더라고요. 그리고 **자기가 돌린 명령이 화면에 실시간으로 흐릅니다.** `git diff` 찍고, 줄번호 붙여서 파일 읽고 하는 게 그대로 보여요.

✅ **작업 위임 — 19.5초**

파일 하나를 요약해달라고 했는데, 같은 이름 파일이 하위 폴더에 여러 개였습니다. **코덱스는 아무거나 고르지 않고 되물었습니다.** "어느 경로 걸 볼까"라고요. 제가 코덱스가 낫다고 생각했던 지점이 정확히 이거였어요.

## ⚠️ 미리 알았으면 좋았을 것들

1. ⚠️ **리뷰 게이트는 함부로 켜지 마세요.** `/codex:setup --enable-review-gate`로 켜는 기능인데, 클로드가 답을 마칠 때마다 코덱스 리뷰가 돌고 문제가 있으면 클로드를 다시 붙잡습니다. 공식 문서에 **클로드와 코덱스가 오래 주고받는 루프가 생기고 사용량이 빠르게 닳을 수 있다**는 경고가 붙어 있고, 세션을 지켜보고 있을 때만 켜라고 적혀 있어요. 끌 때는 `/codex:setup --disable-review-gate`입니다
2. **요금은 ChatGPT 쪽에서 나갑니다.** 클로드 사용량이 아니라 코덱스 한도에서 차감돼요. 대신 **무료 계정으로도 됩니다** — 공식 README에 ChatGPT Free 포함이라고 적혀 있습니다
3. **작업 폴더가 git 루트로 잡힙니다.** 소스를 보면 `git rev-parse --show-toplevel`로 저장소 최상단을 찾아 거기서 돌립니다. 하위 폴더에서 시켜도 코덱스는 최상단 기준으로 찾으니, 특정 폴더만 보게 하려면 경로를 말해줘야 합니다
4. **터미널에 빨간 ERROR 줄이 뜰 수 있습니다.** 연결해둔 외부 도구 토큰이 만료되면 나는 소린데 동작에는 영향이 없었습니다. 다만 화면녹화에는 그대로 찍힙니다

## 🎯 정리

💡 클로드가 짜고 코덱스가 본다. 이게 전부이고, **창을 안 옮겨도 된다는 게 핵심**입니다.

이 플러그인이 새로운 AI를 데려오는 건 아닙니다. 원래 쓰던 코덱스를 클로드 창 안으로 끌어온 것뿐입니다. 그런데 저한테는 그 한 가지가 제일 컸어요.

깔아놓고 안 쓰고 계신 게 있다면, 안 쓰는 진짜 이유가 성능이 아니라 **동선일 수도 있습니다.**
