# 의장 직무실태 점검 프레임워크 및 항목별 체크리스트

> **문서 성격**: 조사관·감사관 관점에서 의장(지방의회 의장 등 합의제 기관의 장)의 직무 수행 실태 — 시간 사용, 동선, 행사 참석, 관용차·업무추진비 집행, 사진 기록 등 — 를 점검하기 위한 일반 프레임워크입니다.
> **개인정보 보호 원칙**: 본 문서는 특정 개인을 지칭하지 않는 일반 점검 양식입니다. 실제 적용 시에는 「개인정보 보호법」상 최소수집 원칙, 목적 외 이용 금지, 제3자(촬영자·면담자 등) 정보의 가명처리 원칙을 준수해야 합니다.

---

## 1. 의장의 법적 지위와 직무

지방의회 의장을 기준으로 하면(「지방자치법」 제58조 등), 의장의 공식 직무는 다음과 같습니다.

| 구분 | 직무 내용 |
|---|---|
| 대표권 | 의회를 대외적으로 대표(협약식, 기관 간 협의, 대외 행사 참석) |
| 의사정리권 | 본회의 의사일정 작성·변경, 회의 진행, 안건 상정 |
| 질서유지권 | 회의장 질서유지, 방청 허가, 발언 중지·퇴장 명령 |
| 사무감독권 | 의회사무처(사무국) 사무 감독, 소속 직원 인사 관여 |
| 기타 | 위원회 출석·발언, 폐회 중 긴급 시 의회 소집 요구 수리, 청원·진정 처리 지휘 |

**감사 시사점**: 위 직무 목록이 "공무"의 판단 기준선이 됩니다. 일정·동선·지출이 위 직무와 합리적 관련성이 있는지가 모든 점검 항목의 공통 질문입니다.

## 2. 의장직에 수반되는 예우·지원 사항

| 항목 | 통상 내용 | 근거·기준 | 감사 착안점 |
|---|---|---|---|
| 업무추진비 | 기관운영·시책추진 목적의 월 한도액 (기관 규모별 차등) | 행정안전부 「지방자치단체 예산편성 운영기준」, 각 자치단체 업무추진비 집행 규칙 | 집행 목적·상대방·시간대·장소의 공무 관련성 |
| 관용차(전용차량) | 의장 전용 승용차 + 운전원 배치 | 「공용차량 관리 규정」(각 기관 훈령) | 사적 사용, 출퇴근 외 심야·휴일 운행, 대기시간 과다 |
| 별도 사무실(의장실) | 집무실 + 접견실, 비서·수행 직원 | 청사 관리 규정, 조직 규칙 | 규모 적정성, 사적 용도 전용 여부 |
| 의전 서열 | 정부의전편람 기준 — 광역의회 의장은 시·도지사에 준하는 예우, 기초의회 의장은 기초단체장에 준하는 지역 내 예우 | 「정부의전편람」(행안부) | 의전이 직무 범위를 넘는 특권으로 운용되는지 |
| 공보(홍보) 지원 | 공식 행사 시 사진·보도자료 등 홍보 담당 부서 지원 | 사무처 분장 규정 | 홍보 인력의 사적 동원 여부 |

## 3. 점검 방법론 — 무엇을, 어떤 자료로 대조하는가

직무 성실성·충실성은 단일 자료로 판단할 수 없으며, **아래 4종 기록의 교차 대조(cross-check)** 로 확인합니다.

1. **일정 기록**: 공식 일정표(비서실 관리), 의사일정, 행사 초청장·계획서
2. **이동 기록**: 관용차 운행일지(출발·도착 시각, 행선지, 주행거리), 유류 구매 전표, 하이패스·주차 기록
3. **지출 기록**: 업무추진비 카드 매출전표(일시·장소·금액·인원), 집행내역 공개 자료
4. **영상·사진 기록**: 공보 부서 촬영 사진(메타데이터 포함), 본인·제3자 촬영 사진, 언론 보도 사진

> **교차 대조의 원리**: "일정표에는 있는데 운행일지에 없다", "업무추진비는 A장소에서 결제됐는데 같은 시각 사진은 B장소다" 와 같은 **불일치(discrepancy)** 가 심층 확인 대상입니다.

## 4. 항목별 체크리스트

### 4-1. 시간·동선

- [ ] 점검 기간의 공식 일정표를 일 단위로 확보했는가
- [ ] 출근·퇴근 시각이 확인 가능한 기록(청사 출입, 차량 운행일지)과 일치하는가
- [ ] 일정 간 이동 동선이 지리적·시간적으로 실현 가능한가 (동일 시간대 중복 일정 여부)
- [ ] 일정 공백 시간대(2시간 이상)의 소재·활동이 소명되는가
- [ ] 근무시간 중 사적 장소(자택, 개인 사업장 등) 체류 기록이 있는가

### 4-2. 행사 참석

- [ ] 참석 행사마다 공식 초청 근거(초청장, 공문)가 있는가
- [ ] 행사의 성격이 의장 직무(대표권 행사)와 관련되는가 — 순수 사적 모임·동창회·종교행사 여부
- [ ] 행사 참석이 실제 이루어졌는가 (주최 측 기록, 사진, 축사 원고와 대조)
- [ ] 행사 참석 빈도가 본연의 의사(議事) 직무를 압박하는 수준인가 (본회의·위원회 출석률과 비교)

### 4-3. 회의 준비·의사 직무

- [ ] 본회의·의장 주재 회의의 출석·주재 실적
- [ ] 회의 전 준비(자료 검토, 사전 협의) 시간이 일정표상 확보되어 있는가
- [ ] 의사일정 작성·안건 처리 지연 사례가 있는가
- [ ] 사무처 보고·결재 처리의 적시성

### 4-4. 관용차

- [ ] 운행일지가 실제 운행과 일치하는가 (유류비·주행거리 정합성: 주행거리 대비 유류 구매량이 차량 공인연비 범위 내인가)
- [ ] 유류비 월별 추이에 비정상적 급증 구간이 있는가
- [ ] 휴일·심야 운행 건별 사유가 기재·소명되는가
- [ ] 대기시간: 행사장 등에서 차량·운전원 대기가 과도하지 않은가 (대기 중 별도 사적 운행 여부)
- [ ] 가족 등 제3자 탑승·사적 사용 정황이 있는가
- [ ] 운전원의 초과근무 내역이 실제 운행 기록과 일치하는가

### 4-5. 업무추진비

- [ ] 건별로 **일시·장소·금액·집행 목적·상대방(인원수)** 이 기록되어 있는가
- [ ] 집행 시간대 점검: 심야(23시 이후)·휴일·연휴 집행 건의 사유 소명
- [ ] 집행 장소 점검: 자택 인근, 근무지와 무관한 원거리, 유흥성 업종 여부
- [ ] 동일 업소 반복 결제, 분할 결제(한도 회피) 패턴이 있는가
- [ ] 집행 상대방이 직무 관련자인가 — 친족·사적 지인·선거구민 개별 접대 여부(공직선거법상 기부행위 저촉 가능성)
- [ ] 집행 내역이 조례·규칙에 따라 공개되고 있는가, 공개 내역과 전표가 일치하는가
- [ ] 명절 선물·경조사비 집행의 대상·기준 적정성

### 4-6. 사진·영상 기록 (촬영 주체별 점검)

사진은 "그 시각, 그 장소에, 누구와 있었는가"를 보여주는 보조 증거이자, 홍보 자원의 사적 유용 여부를 보여주는 독립 점검 대상입니다.

**① 공보(홍보) 담당자가 공식 촬영한 사진**
- [ ] 촬영이 공식 일정(의전 계획)에 따른 것인가
- [ ] 촬영 파일의 메타데이터(일시·위치)가 일정표와 일치하는가
- [ ] 공보 인력이 사적 행사·개인 홍보물(SNS, 의정보고서 외 개인 매체) 촬영에 동원되었는가
- [ ] 촬영·보정·배포에 투입된 인력·예산의 적정성

**② 본인 기기로 촬영한 사진**
- [ ] 근무시간 중 촬영된 사적 성격 사진의 빈도 (직무 소홀 정황 판단의 보조 자료)
- [ ] 본인 촬영 사진이 공적 매체에 공식 활동으로 게시되었는가 (실제 공무 여부와 대조)

**③ 타인에게 부탁하여 타인 기기로 촬영한 사진**
- [ ] 촬영자가 누구인가 — 소속 직원인가, 행사 관계자인가, 직무와 무관한 제3자인가
- [ ] 촬영이 자발적 호의였는가, 지위에 기한 사실상의 지시였는가 (직원이라면 갑질·사적 노무 제공 소지)
- [ ] 직무와 무관한 사람에게 반복적으로 촬영을 부탁한 정황이 있는가
- [ ] 촬영자 개인정보(신원)는 조사 목적 범위에서만 확인하고 보고서에는 가명 처리하는가

**공통**
- [ ] 사진 속 동석자가 직무 관련자인가 — 인허가 이해관계인, 수의계약 업체 관계자 등과의 동석 여부
- [ ] 사진 게시(SNS 등)가 선거법·공무원 행동강령에 저촉되는 홍보인가

### 4-7. 근무시간 중 면담자

- [ ] 의장실 방문자 기록(접견 대장)이 관리되는가
- [ ] 면담 상대방의 직무 관련성 (민원인, 기관 관계자 vs. 사적 지인, 이해관계 업자)
- [ ] 이해관계인 면담 후 관련 안건 처리·인사·계약에 영향 정황이 있는가
- [ ] 면담자 정보는 가명 처리하여 기록하는가 (개인정보 보호)

### 4-8. 종합 판정 — 성실성·충실성

- [ ] 총 근무시간 중 ① 의사 직무 ② 대표 활동(행사) ③ 접견 ④ 소재 불명 시간의 비율 산출
- [ ] 불일치(일정 vs 운행 vs 지출 vs 사진) 건수와 소명 결과 정리
- [ ] 규정 위반(업무추진비 지침, 공용차량 규정, 행동강령) 건별 목록화
- [ ] 제도 개선 필요 사항(운행일지 전산화, 집행내역 상세 공개 등) 도출

## 5. 조사 수행 시 개인정보 보호 유의사항

1. **최소수집**: 직무 관련성 판단에 필요한 범위로 한정. 사생활 영역(가족, 병력, 사적 통신)은 수집하지 않음.
2. **제3자 보호**: 촬영자·면담자·동석자는 보고서에서 "직원 A", "행사 관계자 B" 등으로 가명 처리.
3. **사진 처리**: 증거 사진 속 무관한 인물은 마스킹. 원본은 접근 통제된 저장소에 보관, 목적 달성 후 파기.
4. **공개 시점·범위**: 확인되지 않은 의혹의 실명 공개는 명예훼손 위험. 공개는 확정된 사실과 통계 중심으로.
